Get your classes in

Three ways. The first one runs itself.

Chrome extension

Add it to Chrome, then open Canvas once like you normally would. Come back to LMK and refresh; the first refresh or two can still be empty while it syncs, and that's normal. LMK learns every assignment, what's already submitted, your scores, and which items are in-class or not graded. It re-syncs whenever you're in Canvas.

On a phone? Set up on a laptop once, then sign in with Google (bottom of the page) and your plan appears here.

Or connect Canvas with an access token

For a phone with no laptop around: in Canvas open Account → Settings → New Access Token, copy it, and paste it here. LMK's server then reads your Canvas for you and this phone stays fresh by itself. Delete the token in Canvas any time to stop.

Or paste a page

Open a course in Canvas → Assignments → select the whole page (Ctrl/Cmd-A), copy, paste it here. On a phone, the LMK sync bookmark copies it for you.

Or upload your Canvas calendar (.ics)
  1. In Canvas, open Calendar → click Calendar Feed (bottom right).
  2. Copy the feed link, open it in a new tab — it downloads an .ics file.
  3. Drop that file below (or open it in a text editor and paste its contents).
Drop your .ics file here, or click to browse

A calendar file is a snapshot — re-upload any time to refresh it. Your feed link contains a private token: treat it like a password and don’t post it anywhere. This app never sends your link or your data off this device.
